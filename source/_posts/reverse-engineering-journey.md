最近一段时间，我在工作空间里断断续续做了两类"逆向"：一类是盯着 GitHub 上爆火的 AI 项目，把它们拆开看本土化可行性；另一类是逆向一款 2003 年的 Windows 老游戏，把它重制成浏览器里能跑的版本。两件事看似不相干，底层方法却高度一致。这篇把两条线都记下来。

## 一、寻找 GitHub 爆火 AI 项目并逆向

我的目标不是"跑起来用"，而是评估**它在境内能不能工程化落地**。这一步天然需要先逆向：看清它的外部依赖、数据流、License 边界，才知道堵点在哪。

### 1.1 REA — Reverse Engineer Anything

[REA](https://github.com/morluto/rea)（你 fork 里的 `Hua2026-ai/rea`）是一个把 AI coding agent 接到**本地逆向工具链**的项目，形态是 TypeScript 写的 CLI（126+ 命令）+ 本地 MCP Server（供 agent 调用）。npm 包 `rea-agents` 6.4.0，当时 ⭐49,730，曾列 GitHub Trending #1。

它的核心工作模型是 **Decompile → Understand → Recreate**：
- **Decompile**：打开目标，恢复可读代码/字符串/符号；
- **Understand**：沿控制流与数据流追，直到能解释某个具体功能；
- **Recreate**：把理解转成可运行代码并就地测试。

最值得记的是 **Evidence 机制**——每个结论强制附带证据（文件偏移、行:列、AST 节点、xref），并显式声明"未知边界"。这是它区别于"LLM 靠猜"的关键。我在本地用自建靶标 `ClipVault`（esbuild 打包压缩、移走源码的闭源 Electron 应用）实测过：零源码、仅压缩产物的条件下，rea 完整恢复了应用结构和全部敏感资产，且每个结论都带可验证的 `dist/main.js:行:列`，无幻觉。

实测也踩到一个境内 macOS 用户必撞的坑：macOS 26 新 SDK 会让它的 Swift 进程辅助编译失败。修复是一行环境变量（已验证）：

```bash
export SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.sdk
```

本土化结论很清晰：**rea 本体零改动**，堵点集中在分发与依赖源（npm、GitHub raw、Ghidra/JDK 下载），换国内镜像 + 在 MCP 客户端把模型换成 DeepSeek/通义/GLM 即可在境内跑通全部静态分析能力。合规上要明确：MIT 只覆盖 rea 工具本身，**不覆盖被分析的 App**。

### 1.2 VoiceStudio — 本地版 ElevenLabs

[VoiceStudio](https://github.com/debpalash/VoiceStudio) 是"开源、完全本地运行的 ElevenLabs 替代品"——语音克隆、语音设计、视频配音、转录，支持 646 种语言。当时 **本月 GitHub Trending +36,012 stars**（月增速榜 Top 2）。License 是 **AGPL-3.0-only**。

逆向它的后端（`backend/api/routers/`）能直接还原出"前端如何调后端"的接口契约（`/system/info`、`/api/generation`、`/api/dub/generate` 等），这正是本土化的切入点：拿到接口表，就能用国内语音引擎替换 `engines/` 的实现，或给 `speech_client/` 加一个阿里云/火山引擎的 provider 分支，**前端完全不动**。

它有 4 个明确的境内堵点：模型权重源（HuggingFace，受限）、社区音色 CDN（jsDelivr，时好时坏）、安装脚本域名（`voicestudio.sh`，海外）、依赖源（PyPI/npm）。工作量评估为**中等**——保留本地推理引擎不动，只替换下载/分发基址与云端 provider。风险集中在模型 License（部分需商用申请）与数据出境红线（云端模式会把音频发往境外）。

### 1.3 这类逆向的通用方法论

无论 REA 还是 VoiceStudio，套路都一样：
1. **静态逆向**：解包前端 JS bundle / 反编译桌面 App，全局搜 `https://`、`/api/`、`Authorization`、`apiKey`、`signature` 等关键字，定位端点与签名；
2. **动态抓包**：Web 用 DevTools → Network，桌面/移动用 mitmproxy/Charles 装根证书解密 HTTPS，复现操作抓请求；
3. **协议还原**：记录 `Method + URL + Headers + Body + Auth`，用 `curl` 复现一次确认字段含义。

合规边界必须写清楚：逆向只用于"理解接口契约 → 自建兼容服务 / 本土化替换"，不破解加密、不盗用他人密钥、不绕过付费鉴权；遇到数据出境、内容安全、资质许可等红线明确提示，不绕过。

## 二、北京浮生记：一款 2003 年老游戏的逆向过程

如果说上面是"逆向别人正在维护的 AI 项目"，这一节是逆向一款早已停更的 Windows 游戏——郭祥昊的《北京浮生记》V1.2.2（2003）。它是很多人的童年记忆：你扮演一个揣着 2000 块钱进京倒卖的外地青年，在 40 天里靠低买高卖黑市物品发家，还要躲开被城管追、被人打、假白酒剧毒等随机事件。

### 2.1 逆向到底提取了什么

重制版的游戏数据全部是从原版 `Beijing.exe` 逆向提取，再结构化落进代码。直接在 `bjfsj-web/index.html` 里就能看到原始数组：

- **8 种黑市物品**（`ITEMS`，代码 line 140–149）：盗版 VCD/游戏、进口玩具、伪劣化妆品、进口香烟、假白酒（剧毒）、水货手机、《上海小宝贝》（禁书）、走私汽车——每种带价格区间与 `illegal` 标记；
- **20 个北京地点**（`PLACES`，line 151–152）：八角地铁、翠微路、菜户营、北辰西路、文津街、三元东桥、永定门、海淀大街、方庄、永安里、苹果园、公主坟、长椿街、积水潭、复兴门、东直门、崇文门、西直门、北京站、建国门；
- **43 条随机事件**（`EVENTS`，line 154–198）：从"被民工打""被红袖章罚暂住证"到"黑客入侵银行修改你的存款""厦门老同学资助两部走私汽车"，每条带 `type` 影响后果（扣钱/扣血/涨声望/改价格/送物品）；
- **称号与富人榜**：`FAME_NAMES`（德高望重/杰出青年/一般般/争议人物/江湖唾弃）、`RANK_TITLES`（北京第一金手指等 5 个）、`NPCS`（9 个富人榜 NPC，取自原版 `score.txt` 排行）；
- **美术与音效**：`assets/` 下正好 **8 张 BITMAP 图 + 16 个 wav 音效**（Airport、buy、death、hit、money、vomit 等），与原版资源一一对应。

### 2.2 关键机制还原

几个原版的核心玩法，重制时都按逆向结果如实还原了：
- **日息 10%**：每奔走一个地点算一天，欠款按 10% 滚动（`index.html` line 92「欠款涨 10%」）；
- **还村长钱**：初始欠村长 5500 元，随时可还（`payDebt()`）；
- **银行 / 医院**：存取款（`openBank()`）、治病回血（`openHospital()`）；
- **老板键伪装层**：最经典的"摸鱼神器"——按下老板键，游戏瞬间切换成一份《关于做好本月工作的一些具体想法》的工作文档（`bossHere()` → `bossLeave()`），老板一走点一下就回到游戏；
- **三种结局**：发财衣锦还乡（村长在电话里下跪、想把女儿嫁给你）、平庸回家（40 天到期"该回去结婚去了"）、失败被遣返或健康危机倒在街头。

### 2.3 还原度锚点：原版权威设定

倒卖游戏最容易"手感不对"的地方是初始数值。重制版的关键设定取自原版 `Readme.txt` 解码后的权威值：**初始现金 2000 元、欠村长 5500 元、日息 10%、游戏周期 40 天**——这些不是拍脑袋定的，而是逆向原版文案后对齐的。

### 2.4 Web 重制与实测

成品是**单文件 HTML5**（`bjfsj-web/index.html` + `assets/` + `frags.json` 数据分离），纯原生 JS + CSS 变量，无任何构建依赖。验证方式是用 **Microsoft Edge headless（Chrome DevTools Protocol）** 跑通全部机制：初始化、买卖、奔走触发事件、银行/医院/还钱、老板键切换、三种结局分支——全机制通过，**零 JS 异常**。

## 三、两条线的共性

把这两类逆向放在一起看，共性很明显：

1. **逆向的本质是"在不破坏的前提下理解"**。REA 强调 Evidence（文件:行:列）、北京浮生记强调"数据取自原版文案对齐"——两者都拒绝靠猜，都要求结论可回溯。
2. **数据 / 接口是核心资产**。无论是 AI 项目的外部依赖堵点，还是老游戏的物品/地名/事件表，真正的价值都在结构化提取出来的那层。
3. **合规边界先讲清**。MIT/AGPL 覆盖工具不覆盖被分析对象；老游戏重制要尊重原作者版权。能做的（互操作性研究、学习怀旧、自有软件审计）和不能做的（破解加密、盗用密钥、绕过付费）必须划清。

## 结语

工作空间里这两块成果都在本地：AI 项目逆向有两份落地报告（`REA-逆向与本土化报告.md`、`VoiceStudio-逆向与本土化报告.md`），北京浮生记重制在 `bjfsj-web/`。前者回答了"爆火项目能不能在境内跑"，后者把一段 2003 年的记忆搬进了浏览器。逆向这件事，价值不在于"破解"，而在于把别人封装好的东西拆开看明白，再决定怎么用、怎么落地。
